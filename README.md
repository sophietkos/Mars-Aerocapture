**About the Project**

This project develops a Python-based aerocapture model to investigate high-energy Mars arrival conditions associated with laser thermal propulsion (LTP). The model uses a predictor-corrector bank angle modulation guidance algorithm to generate aerocapture trajectories and evaluate the feasibility of the maneuver. Parameter sweeps and Monte Carlo simulations were performed to investigate entry corridors, sensitivity to key parameters, and the effects of uncertainty on aerocapture performance.

**Repository Contents**

This repository contains the main aerocapture model, parameter sweep codes, Monte Carlo simulation code, generated results in CSV format, and plots in SVG format.
